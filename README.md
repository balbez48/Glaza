
# Мобильное приложение «Glaza»

**«Glaza» (NeyroGlaza)** — это инклюзивное мобильное приложение-ассистент, разработанное для людей с глубокими нарушениями зрения и пожилых граждан. Проект построен на базе искусственного интеллекта и компьютерного зрения, объединяя независимые облачные контуры в единую отказоустойчивую сплит-архитектуру.

Основная цель проекта — возвращение незрячим пользователям базовой бытовой автономности. Приложение позволяет ориентироваться в пространстве, читать плоскопечатные тексты и безопасно взаимодействовать с наличными бумажными деньгами без привлечения зрячих помощников или волонтеров.

---

## 🚀 Ключевые возможности и режимы работы

Интерфейс приложения адаптирован для использования полностью вслепую, содержит крупные контрастные зоны нажатия, сопровождается тактильным виброоткликом (Haptics) и встроенными речевыми подсказками. Приложение работает в трех основных режимах:

*   **🟠 Режим «Среда»:** Делает снимок окружающей обстановки и отправляет его на ноду Сбера (модель GigaChat Vision), формируя детальное художественное описание пространства (мебель, люди, препятствия) для помощи в ориентации.
*   **🔵 Режим «Текст»:** Оптическое распознавание (OCR) текстов на документах, этикетках или вывесках с помощью Yandex Vision и последующее зачитывание встроенным синтезатором речи.
*   **🟢 Режим «Деньги»:** Специализированный нейросетевой режим для мгновенного определения номинала и валюты бумажных банкнот через контур Yandex Cloud (Vision OCR + YandexGPT).

Дополнительно реализовано динамическое управление плеером (широкая кнопка «Повторить озвучку / Остановить чтение») и модальное окно настроек для регулирования скорости речи от 0.5x до 2.0x и смены системных голосов.

## 🛠️ Архитектура и стек технологий

Проект реализован на базе клиент-серверной архитектуры (Stateless-бэкенд) с распределенной обработкой данных:

*   **Frontend (Мобильный клиент):** 
    *   Язык: TypeScript / JavaScript
    *   Фреймворк: React Native (Expo)
    *   Периферийные модули: `CameraView` (захват фото), `enableTorch` (управление вспышкой), `Haptics` (тактильная отдача) и `Expo-Speech` (синтез речи).
    *   Кэширование конфигураций: `AsyncStorage`.
*   **Backend (Сервер-оркестратор):**
    *   Язык: Python 3.11+
    *   Веб-фреймворк: FastAPI (асинхронная обработка REST API Multipart-запросов)
    *   Контейнеризация: Docker / Docker Compose.
*   **Инфраструктура и ИИ-контуры:**
    *   Нода «Среда» развернута в Cloud.ru (Container Apps).
    *   Нода «Текст и Деньги» развернута в Yandex Cloud (Serverless Containers).
    *   Транспортный уровень защищен обязательным шифрованием данных по протоколу HTTPS/TLS.

## 🧠 Инженерные решения по оптимизации ИИ

В рамках разработки бэкенда команда реализовала ряд программных решений для повышения достоверности ответов и ликвидации галлюцинаций LLM-моделей:
1.  **Подавление галлюцинаций (`temperature: 0.1`):** В Payload-запросах к YandexGPT креативность модели снижена до минимума, что заставляет ИИ отвечать строго на основе фактов с картинки.
2.  **Валидация через регулярные выражения (RegEx):** В режиме «Деньги» сырой текстовый OCR-мусор (серийные номера, юридические надписи) проверяется бэкендом на наличие цифровых масок номиналов валют. При отсутствии совпадений система возвращает безопасный статус *«Купюра не распознана»*, защищая пользователя от дезинформации.
3.  **Отказоустойчивый Сплит-контур:** При падении или технических работах на стороне одного из облачных провайдеров, приложение аппаратно изолирует упавшую ноду, сохраняя работоспособность остальных критически важных функций.
